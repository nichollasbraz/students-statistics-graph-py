A Python project developed to analyze and visualize the distribution of student grades using statistical methods and data visualization libraries. The project generates randomized grades, calculates final averages, and displays the results through histograms with density curves.

## Features

• Student grade analysis\
• Randomized grade generation\
• Final average calculation\
• Histogram visualization\
• Kernel Density Estimation **(KDE)**\
• Statistical distribution analysis.

## Run

```bash
python main.py
```
